多媒体展示系统-网络游鱼
在同一个局域网内的各个主机上运行本系统，个主机形成一个网络，多条游鱼可以在这个网络中的各个主机之间来回游动，当游鱼游出某个屏幕时就进入前进方向的下一个相邻屏幕，实现游鱼在网络中各个主机屏幕之间的随机游动。系统需要展示游鱼的三维运动动画，鱼儿游动时水的声音。
系统功能需求
 局域网自动组网功能
程序启动后，自动发现同一局域网内的其他运行主机
支持至少 3 台计算机 组成多屏联动系统
自动建立通信，确定屏幕之间的左右 / 上下相邻关系
提供简单的组网状态显示
游鱼动画展示功能
绘制多条2D 或 3D 游鱼动画
鱼具备：随机游动方向、速度、大小、颜色
鱼游动时具有自然摆尾、前进、转向动画
支持同时显示多条鱼（可配置数量）
跨屏游动核心功能（最重要）
当鱼游出当前屏幕边界时，自动进入相邻主机的屏幕
进入方向与游出方向保持一致（向右游出 → 从右边机器左侧进入）
多机之间实时同步鱼的位置、方向、速度
跨屏过程平滑、无卡顿、不重复、不消失
音效与特效
播放水流背景音效
鱼游动时可添加水波纹特效
支持音效开关
参数配置与控制
可设置：鱼的数量、游动速度
可启动、暂停、重置演示
可开启 / 关闭跨屏联动模式
显示当前联机状态
界面展示
全屏 / 窗口模式展示游鱼动画
实时显示联机主机数量、鱼数量、运行状态
网络通信需求
通信方式：UDP 广播 / 组播
数据同步：鱼的坐标、方向、速度、编号
低延迟：跨屏切换延迟 < 100ms
支持动态加入 / 退出主机
非功能需求
动画流畅：帧率 ≥ 25 FPS
多机同步准确，不出现鱼重复或丢失

操作简单，一键启动、自动联机
可在普通 PC 机运行，无需特殊硬件
业务流程
各主机启动程序 → 自动局域网搜索同伴主机
建立多机联动，确定屏幕拓扑关系
生成多条游鱼，在本机屏幕随机游动
鱼游出屏幕边界 → 发送消息给相邻主机
相邻主机接收消息 → 在对应位置生成鱼并继续游动
全程播放水流音效，展示多屏联动效果
用户可调整鱼数量、速度，启停演示

## CyberFish MVP 实现说明

本仓库已实现一个从零构建的 Python + Pygame 版本。实现重点是可运行的多主机 MVP：单机水族箱动画、UDP 局域网发现、手动校准相邻屏幕、鱼跨屏移交、状态面板、基础水声音效和 headless 测试。

背景声使用项目内置资源 `cyberfish/assets/audio/background_fish_in_river.mp3`；如果运行环境无法解码 MP3，会自动回退到程序合成的水流音。

参考项目只借鉴设计思路，不复制代码或资源：

- `victenna/Aquarium`：简单鱼游动动画思路。
- `david-svitov/fishscanner`：鱼对象与趣味展示思路。
- `smidmatej/Aquarium`：Boids 鱼群行为、摆尾与群游思路。
- `christinaou/3d-aquarium`：3D 水族馆结构思路，本项目用 Pygame 伪 3D 落地。
- `openscopeproject/MultiScreenSaver`、`1j01/nw-screensaver`：全屏和多屏展示思路。

## 运行方式

```bash
venv/bin/python -m cyberfish
```

首次启动会自动生成 `config.json`。如果需要临时关闭网络：

```bash
venv/bin/python -m cyberfish --no-network
```

自动化 smoke 检查：

```bash
SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy venv/bin/python -m cyberfish --headless-smoke --duration 5 --no-network
```

## 界面控制台

程序左上角提供中文点击式控制台，不需要记忆键盘快捷键：

- `暂停 / 继续`：暂停或恢复鱼群游动。
- `重置`：重新生成鱼群。
- `退出`：关闭程序。
- `网络 开 / 关`：开启或关闭跨屏联动。
- `音效 开 / 关`：开启或关闭背景水声。
- `全屏 / 窗口`：切换显示模式。
- `鱼数量 - / +`：减少或增加鱼数量。
- `速度 - / +`：降低或提高鱼游动速度。
- `选择在线主机`：点击在线主机按钮作为当前要设置的邻居。
- `设置相邻方向`：点击 `左 / 右 / 上 / 下`，把当前选中的在线主机保存为对应方向的邻居。

`Esc` 仅保留为退出兜底操作。

## 多机联动校准

1. 在同一局域网的多台主机上运行 `venv/bin/python -m cyberfish`。
2. 等待左上角控制台中 `在线主机` 数量出现。
3. 在左上角控制台的 `选择在线主机` 区域点击某台在线主机。
4. 在 `设置相邻方向` 区域点击 `左 / 右 / 上 / 下` 保存该主机与本机的相邻方向。
5. 每台机器都按真实摆放关系完成一次校准。

鱼从已配置邻接方向游出时，会通过 UDP `fish_transfer` 消息发送给对应主机；接收主机会发送 `transfer_ack`。如果发送端短时间内没有收到确认，会把鱼放回本机边缘，避免鱼丢失。

## 配置文件

`config.json` 会自动创建并持久化以下关键项：

- `node_id`：本机节点 ID。
- `udp_port` / `broadcast_host`：UDP 发现与传输配置。
- `fullscreen` / `display_index` / `window_width` / `window_height`：显示配置。
- `fish_count` / `speed_multiplier`：鱼数量与速度。
- `sound_enabled` / `network_enabled`：音效与跨屏联动开关。
- `topology`：`left`、`right`、`up`、`down` 四个方向对应的邻居节点 ID。
